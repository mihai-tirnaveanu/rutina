# Rutina de antrenament

Jurnal de antrenament pentru telefon: kg, repetări, observații, poze și videouri pentru fiecare exercițiu.

- Aplicația: https://mihai-tirnaveanu.github.io/rutina/
- Datele (antrenamente, poze, videouri) se salvează în repo-ul privat `rutina-date`, prin tokenul introdus pe telefon. Acest repo conține doar codul aplicației, fără nicio dată.

## Structura datelor din `rutina-date`

```
rutina.json              zilele și exercițiile
antrenamente/*.json      câte un fișier pe antrenament
media/*                  poze și videouri
```
